# ✅ To-Do List 2

A simple, professional, and user-friendly **To-Do List Web Application** designed to help users organize daily tasks, track progress, and manage their activities efficiently.

## 🚀 Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 🔄 Update task status
* 🔍 Search tasks
* 📅 Organize daily activities
* 💾 Store task data
* 📱 Responsive and user-friendly interface
* ⚡ Fast and lightweight application

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and dynamic functionality
* **Local Storage** – Browser-based task storage

## ⚙️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add, edit, complete, or delete your tasks.



## 🎯 Project Objective

The objective of this project is to build a simple task-management application while demonstrating practical knowledge of **HTML, CSS, JavaScript, DOM manipulation, event handling, and browser storage**.
